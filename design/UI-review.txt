NetShift UI implementation and review
====================================

Implemented
- First-run welcome with Shifty and a persistent Get started action.
- Persistent light/dark preference, a sun/moon switch, and a 1200 ms circular theme reveal.
- Animated chameleon with independent head, waving arm, resting arm, legs and tail pivots. Limb roots use opaque source anchors inside the torso so both wave extremes stay connected. The near-side resting arm is mirrored and drawn in front, showing the full shoulder, elbow and hand instead of hiding it behind the belly.
- Shifty's face is the launcher icon, with an inset foreground for Android adaptive masks and themed-icon support.
- Wi-Fi uses mint/cyan, mobile data uses warm gold, and offline uses blue. Theme changes also adjust Shifty's hue and lighting.
- One shared 1536 x 1024 transparent texture atlas (approximately 2 MB compressed) used by the native Compose canvas rig.
- Bottom navigation with sampled Riff 32 stretch/overshoot, animated foreground contrast, and large-text sizing.
- History cards with actual saved metrics; rounded comparison prompt; real comparison charts using TestRepository.observeComparisons().
- Stage meter uses actual completed probe counts or downloaded bytes. Acquisition/warm-up/saving have indeterminate progress.
- Animated result values and expandable activity verdicts.
- Sticky Get started and Start/Cancel actions; native scrolling; system animation-scale support.

References and adaptations
- Figma: https://www.figma.com/design/k73lIwiJuXYlwX5hZe42zV/NetShift
- Riff 32: node 1:1949. The first 1133 ms transition's sampled geometry is in RiffMotion.kt. User selection drives it instead of the reference's automatic 6-second slideshow.
- Riff 40: node 2:6982. Native circular reveal uses an old-frame overlay and the reference's approximately 1200 ms wipe.
- Connect Prompt: node 3:516. Rounded bottom sheet, mascot and stacked actions are adapted to local saved comparisons. No service connection is simulated.
- Existing app-specific icons are retained for Live, Test, History and Handoffs.
- Native animation APIs: https://developer.android.com/develop/ui/compose/animation/value-based
- Native canvas APIs: https://developer.android.com/develop/ui/compose/graphics/draw/overview

Scope
- Measurement algorithms, limits and verdict thresholds are unchanged.
- Both original launcher entries are preserved. Open NetShift for the new UI; the separate NetShift DEBUG entry remains a development tool.
- Handoff tracking remains unavailable until its backend/service is implemented. Its UI does not imply that tracking is active.
- Source and artwork are maintained on enhanced-ui. Generated APKs, emulator state and local build caches remain outside version control.
- Emulator fixtures use test-only measurements and do not insert fake history into the app.
